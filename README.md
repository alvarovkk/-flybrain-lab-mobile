# FlyBrain Lab Mobile

PWA móvil experimental con una mosca autónoma y visualización de actividad neuronal simulada.

## Importante
La actividad neuronal y el comportamiento de esta versión son simulados. La estructura está preparada para integrar datos estructurales FlyWire/FAFB; no representa una grabación en tiempo real de una mosca viva.

## GitHub Pages
Sube `index.html`, `style.css`, `app.js` y `manifest.json` a la raíz del repositorio y activa Pages desde Settings → Pages.
